ProxyProviders Quick Start Documentation

ProxyProviders

One interface for proxy vendors, many Python clients.

Get proxies from Webshare, Bright Data or your own list, and use them with requests, httpx, aiohttp, Playwright, Scrapy, Crawlee or curl without writing vendor-specific code. Swap providers by changing one line.

import requests
from proxyproviders import Webshare, ProxyFormat

provider = Webshare(api_key="your-api-key")  # or BrightData(...), or ProxyList([...])
proxy = provider.get_proxy()

response = requests.get(
    "https://httpbin.org/ip", proxies=proxy.format(ProxyFormat.REQUESTS)
)

Installation

python -m pip install proxyproviders

Python 3.10 or newer. The full documentation is here, and there are runnable examples in the repository.

Using an AI coding assistant? Point it at llms.txt, a short summary of the API written for assistants.

📺 Video Tutorial: Watch the quick start guide on YouTube for a walkthrough of getting started with ProxyProviders.

What It Does

Every proxy vendor has its own API, and every HTTP client wants its proxy in a different shape. ProxyProviders sits between the two:

Webshare | Bright Data | your own list
                 ↓
   ProxyProvider  →  Proxy
                 ↓
requests | httpx | aiohttp | Playwright | Scrapy | Crawlee | curl

  • Provider API handled for you. Proxies are fetched from the vendor, cached, and refreshed on an interval.

  • One Proxy model. Host, port, credentials, country and protocols look the same whichever vendor they came from.

  • One line to hand it to your client. proxy.format(...) produces what each client expects, with credentials percent-encoded correctly.

  • Vendor-neutral code. Anything written against ProxyProvider works with every provider, so switching vendor does not touch the rest of your application.

Rotation and retries are available if you want them (RotatingSession), and stay out of the way if your framework already does that.

Quick Start Guide

List the proxies from a provider:

import os
from proxyproviders import Webshare

provider = Webshare(api_key=os.environ["WEBSHARE_API_KEY"])

proxies = provider.list_proxies()
print(proxies)  # passwords are left out of the printed output

Or take one at a time. get_proxy() cycles through the list in order by default:

proxy = provider.get_proxy()
print(proxy.proxy_address, proxy.port, proxy.country_code)

Providers take their own options. Webshare passes search_params to the Webshare API, so this returns only proxies based in the US:

provider = Webshare(
    api_key=os.environ["WEBSHARE_API_KEY"], search_params={"country_code_in": "US"}
)

Because every provider has the same interface, code written against ProxyProvider does not care which vendor is behind it:

import os
import requests
from proxyproviders import BrightData, ProxyFormat, ProxyProvider, Webshare


def fetch_ip(provider: ProxyProvider) -> str:
    proxy = provider.get_proxy()
    response = requests.get(
        "https://httpbin.org/ip", proxies=proxy.format(ProxyFormat.REQUESTS)
    )
    return response.json()["origin"]


fetch_ip(Webshare(api_key=os.environ["WEBSHARE_API_KEY"]))
fetch_ip(BrightData(api_key=os.environ["BRIGHTDATA_API_KEY"], zone="my_zone"))

That is how other libraries, such as my TikTokAPI package, accept any proxy vendor without knowing about it.

Using Proxies With Your HTTP Client

Every example below starts with a provider, which can be any provider from the table above.

Python requests With Rotating Proxies

import requests
from proxyproviders import ProxyFormat

proxy = provider.get_proxy()
response = requests.get(
    "https://httpbin.org/ip", proxies=proxy.format(ProxyFormat.REQUESTS)
)

Each get_proxy() call returns the next proxy, so calling it per request rotates through your proxies. To have rotation and retries done for you, use RotatingSession.

httpx Proxy

httpx (0.26 or newer) takes one proxy URL in its proxy= argument, for both the sync and async clients:

import httpx
from proxyproviders import ProxyFormat

with httpx.Client(proxy=provider.get_proxy().format(ProxyFormat.HTTPX)) as client:
    response = client.get("https://httpbin.org/ip")

async with httpx.AsyncClient(
    proxy=provider.get_proxy().format(ProxyFormat.HTTPX)
) as client:
    response = await client.get("https://httpbin.org/ip")

aiohttp Proxy

import aiohttp
from proxyproviders import ProxyFormat

async with aiohttp.ClientSession() as session:
    async with session.get(
        "https://httpbin.org/ip", proxy=provider.get_proxy().format(ProxyFormat.AIOHTTP)
    ) as response:
        print(await response.json())

Playwright Proxy in Python

from playwright.sync_api import sync_playwright
from proxyproviders import ProxyFormat

with sync_playwright() as p:
    browser = p.chromium.launch()
    context = browser.new_context(
        proxy=provider.get_proxy().format(ProxyFormat.PLAYWRIGHT)
    )
    page = context.new_page()
    page.goto("https://httpbin.org/ip")

Give each browser context its own get_proxy() call to spread contexts across proxies. The same dictionary works for p.chromium.launch(proxy=...).

Scrapy Proxy

Scrapy’s built-in HttpProxyMiddleware reads the proxy from request.meta and takes the credentials out of the URL:

import scrapy
from proxyproviders import ProxyFormat


class IpSpider(scrapy.Spider):
    name = "ip"

    def start_requests(self):
        yield scrapy.Request(
            "https://httpbin.org/ip",
            meta={"proxy": provider.get_proxy().format(ProxyFormat.SCRAPY)},
        )

Crawlee for Python Proxy

Crawlee rotates proxies and manages sessions itself, so hand it the whole list:

from crawlee.proxy_configuration import ProxyConfiguration

proxy_configuration = ProxyConfiguration(
    proxy_urls=[proxy.to_url() for proxy in provider.list_proxies()]
)

curl and Subprocesses

import os
import subprocess
from proxyproviders import ProxyFormat

proxy = provider.get_proxy()

# As curl arguments: ["-x", "http://user:pass@host:port"]
subprocess.run(["curl", *proxy.format(ProxyFormat.CURL), "https://httpbin.org/ip"])

# Or as HTTP_PROXY / HTTPS_PROXY for any program that reads them
subprocess.run(
    ["curl", "https://httpbin.org/ip"],
    env={**os.environ, **proxy.format(ProxyFormat.ENV)},
)

Use Your Own Proxy List

If your vendor has no provider here, or you simply have a list of proxies, ProxyList gives them the same interface as everything else:

from proxyproviders import ProxyList

provider = ProxyList(
    [
        "http://user:pass@203.0.113.7:8080",
        "203.0.113.8:8080:user:pass",
        "socks5://user:pass@203.0.113.9:1080",
    ]
)

# Or one proxy per line from a file (blank lines and # comments are skipped)
provider = ProxyList.from_file("proxies.txt")

A single proxy can be parsed with Proxy.from_string(...), which accepts a URL, user:pass@host:port, host:port or host:port:user:pass.

Automatic Rotation and Retries

RotatingSession is a requests.Session that picks a proxy for every request. If a request cannot get through its proxy, that proxy is set aside for a while and the request is sent again through the next one:

from proxyproviders import RotatingSession

session = RotatingSession(provider, max_retries=3)

response = session.get("https://httpbin.org/ip", timeout=10)
print(response.json(), session.last_proxy)

It is opt-in: nothing changes for code that calls get_proxy() itself. What it treats as a failed proxy, and when it sends the request again:

  • Could not connect to the proxy, or open a tunnel through it: retried for any HTTP method, because the request never reached the target.

  • Any other connection error or timeout, such as a proxy that drops the connection or stops responding: retried for GET, HEAD and OPTIONS only. A POST may already have been acted on, so the error is raised instead of sending it twice.

  • A 407 Proxy Authentication Required response, or any status you list in retry_statuses: retried for any method.

Ordinary error statuses such as 404 or 500 are returned as usual. File uploads and streamed bodies are sent once and never retried. Deciding that a response means your proxy is blocked is up to you, for example:

session = RotatingSession(provider, max_retries=3, retry_statuses={403, 429})

For httpx 0.26 or newer, sync or async, the same behaviour comes as a transport. Install it with pip install "proxyproviders[httpx]":

import httpx
from proxyproviders.httpx_transport import AsyncRotatingTransport, RotatingTransport

with httpx.Client(transport=RotatingTransport(provider, max_retries=3)) as client:
    response = client.get("https://httpbin.org/ip")

async with httpx.AsyncClient(transport=AsyncRotatingTransport(provider)) as client:
    response = await client.get("https://httpbin.org/ip")

Reporting Failed Proxies

When you make requests yourself, tell the provider about a proxy that failed and get_proxy() will avoid it for failure_cooldown seconds (60 by default):

import requests
from proxyproviders import ProxyFormat

proxy = provider.get_proxy()
try:
    response = requests.get(url, proxies=proxy.format(ProxyFormat.REQUESTS), timeout=10)
except requests.exceptions.ProxyError:
    provider.report_failure(proxy)

provider.report_success(proxy) puts it back early, and provider.available_proxies() lists the ones not currently set aside. If every proxy has failed, get_proxy() still returns one instead of raising. This works the same with every HTTP client, sync or async.

Choosing Which Proxy You Get

get_proxy() takes a selection algorithm. The default is round robin.

from proxyproviders.algorithms import First, Random, RoundRobin

proxy = provider.get_proxy()  # RoundRobin: next proxy in order
proxy = provider.get_proxy(Random())  # a random proxy
proxy = provider.get_proxy(First())  # always the first proxy

# A RoundRobin you create keeps its own position, separate from the provider's default
round_robin = RoundRobin()
proxy1 = provider.get_proxy(round_robin)
proxy2 = provider.get_proxy(round_robin)  # next in sequence

Write your own by subclassing Algorithm:

from typing import List
from proxyproviders import Proxy
from proxyproviders.algorithms import Algorithm


class USProxyAlgorithm(Algorithm):
    """Prefers US proxies, falls back to the first available."""

    def select(self, proxies: List[Proxy]) -> Proxy:
        for proxy in proxies:
            if proxy.country_code == "US":
                return proxy
        return proxies[0]


proxy = provider.get_proxy(USProxyAlgorithm())

Configuration

Options shared by every provider live in ProxyConfig (full reference):

Option

Default

Meaning

refresh_interval

600

Seconds before the proxy list is fetched again. 0 fetches once and never refreshes.

timeout

30

Seconds to wait on each call to the provider’s API

refresh_retry_delay

30

If a refresh fails, the previous list keeps being served and the API is tried again after this many seconds

import os
import time
from proxyproviders import ProxyConfig, Webshare

config = ProxyConfig(refresh_interval=3)
ws = Webshare(api_key=os.environ["WEBSHARE_API_KEY"], config=config)

ws.list_proxies()  # calls the API
ws.list_proxies()  # cached

time.sleep(5)
ws.list_proxies()  # calls the API again, since more than 3s have passed

list_proxies() and get_proxy() are safe to call from several threads.

SOCKS Proxies

A proxy whose protocols only lists a SOCKS scheme, e.g. ["socks5"], is formatted with that scheme for every client:

proxy.format(ProxyFormat.REQUESTS)
# {'http': 'socks5://user:pass@host:1080', 'https': 'socks5://user:pass@host:1080'}

Your HTTP client needs SOCKS support for this to work. For requests, install it with:

python -m pip install "proxyproviders[socks]"

httpx needs httpx[socks]. aiohttp and Scrapy have no built-in SOCKS support.

Making Your Own Proxy Provider

Subclass ProxyProvider and return a list of Proxy objects from _fetch_proxies. Caching, refreshing, selection, formatting and failure reporting then work without any more code:

from typing import List, Optional
from proxyproviders import Proxy, ProxyConfig, ProxyProvider


class MyProxyProvider(ProxyProvider):
    def __init__(self, config: Optional[ProxyConfig] = None):
        super().__init__(config=config)

    def _fetch_proxies(self) -> List[Proxy]:
        # Call your vendor's API here and convert each entry
        return [
            Proxy(
                id="1",
                username="username",
                password="password",
                proxy_address="192.168.1.1",
                port=80,
            )
        ]


provider = MyProxyProvider()
proxy = provider.get_proxy()

If you write one for a vendor other people use, please contribute it back. CONTRIBUTING.md has the steps, and the repository includes an add-provider skill that walks a coding agent such as Claude Code through the whole process.

class proxyproviders.proxy_provider.ProxyConfig(refresh_interval: float = 600, timeout: float = 30, refresh_retry_delay: float = 30, failure_cooldown: float = 60)[source]

Bases: object

Provides standard shared configuration options for all proxy providers.

Example:

from proxyproviders import Webshare, ProxyConfig

config = ProxyConfig(refresh_interval=5)

refresh_interval: float = 600

Duration in seconds after which the proxy list is refreshed to fetch new proxies. Set to 0 to disable automatic refreshing after the initial fetch.

timeout: float = 30

Timeout in seconds for each request to the provider’s API, so a stalled connection raises instead of hanging forever.

refresh_retry_delay: float = 30

After an automatic refresh fails and the previous proxy list is served instead, wait this many seconds before trying the provider’s API again.

failure_cooldown: float = 60

How long, in seconds, ProxyProvider.get_proxy() avoids a proxy after it was passed to ProxyProvider.report_failure().

list_proxies(force_refresh: bool = False) → List[Proxy][source]

Returns the stored proxies, fetching them from the provider first when they are missing or older than refresh_interval.

Safe to call from several threads: when the list is stale only one thread fetches and the others wait for its result.

If an automatic refresh fails and an earlier list is available, that list is returned and a warning is logged, so one failed call to the provider’s API does not take your proxies away. The error is raised when there is nothing to fall back on, or when force_refresh is True.

report_failure(proxy: Proxy, cooldown: float | None = None) → None[source]

Tell the provider a proxy just failed, so get_proxy() avoids it for a while.

Nothing calls this for you unless you use RotatingSession; it is how your own code feeds back a connection error, a ban or a bad response. The proxy stays in list_proxies() and comes back into rotation once the cooldown has passed. If every proxy is cooling down, get_proxy() still returns one.

  • cooldown – Seconds to avoid it for. Defaults to ProxyConfig.failure_cooldown.

... except requests.exceptions.ProxyError:
...     provider.report_failure(proxy)

A provider for proxies you already have, from any vendor.

Use it when your vendor has no provider here yet, or when you manage the list yourself. You get the same interface as every other provider: selection algorithms, output formats, failure reporting and RotatingSession.

Parameters:

  • proxies – The proxies, each either a Proxy or text in any form Proxy.from_string() accepts: a URL such as http://user:pass@host:port or socks5://host:port, or host:port:user:pass

  • config – Configuration for the proxy provider. View the ProxyConfig class docs for more information.

Raises:

ValueError – If an entry cannot be parsed, or the list is empty

Example:

from proxyproviders import ProxyList

provider = ProxyList(
    [
        "http://user:pass@203.0.113.7:8080",
        "203.0.113.8:8080:user:pass",
        "socks5://user:pass@203.0.113.9:1080",
    ]
)

proxy = provider.get_proxy()

# Or one proxy per line from a file, ignoring blank lines and # comments
provider = ProxyList.from_file("proxies.txt")

class proxyproviders.session.RotatingSession(provider: ProxyProvider, algorithm: Algorithm | None = None, max_retries: int = 2, retry_statuses: Collection[int] = ())[source]

Bases: Session

A requests.Session that routes each request through a proxy from a provider.

Every request asks the provider for a proxy. If the request fails to get through the proxy, the proxy is reported with report_failure() and the request is tried again on the next one, up to max_retries more times. It works with any provider, including ProxyList.

What counts as a failed proxy, and when the request is sent again:

  • Failing to connect to the proxy, or to open a tunnel through it: retried for any HTTP method, because the request never reached the target.

  • Any other connection error or timeout, such as a proxy that drops the connection or stops responding: retried for GET, HEAD and OPTIONS only. Other methods may already have been acted on, so the error is raised instead.

  • A 407 Proxy Authentication Required response, or any status you list in retry_statuses: retried for any method.

Anything else, including ordinary error statuses such as 404 or 500, is returned or raised exactly as requests would. A TLS error is raised without blaming the proxy, since it usually comes from the target. A slow target cannot be told apart from a slow proxy, so a read timeout counts against the proxy. Deciding that a response means “banned” is left to you: list statuses in retry_statuses or call report_failure yourself.

A request made with an explicit proxies= argument is sent as given, with no rotation. Requests that upload files or stream their body are sent once and never retried, since the body cannot be read twice.

Parameters:

  • provider – Where proxies come from

  • algorithm – Selection algorithm, as for provider.get_proxy(). Defaults to the provider’s round robin.

  • max_retries – How many more proxies to try after the first one fails

  • retry_statuses – Extra response status codes treated as a failed proxy, e.g. {403, 429} for a target that blocks proxies. 407 is always included.

Example:

from proxyproviders import Webshare
from proxyproviders.session import RotatingSession

session = RotatingSession(Webshare(api_key="your-api-key"), max_retries=3)

response = session.get("https://httpbin.org/ip", timeout=10)
print(response.json(), session.last_proxy)

class proxyproviders.httpx_transport.RotatingTransport(*args: Any, **kwargs: Any)[source]

Bases: _Rotation, BaseTransport

An httpx transport that routes each request through a proxy from a provider.

Every request asks the provider for a proxy. If the request fails to get through, the proxy is reported with report_failure() and the request is sent again through the next one, up to max_retries more times.

What counts as a failed proxy:

  • a connect error, connect timeout or proxy error: retried for any HTTP method, because the request never reached the target

  • a read or write error or timeout, or a broken response: retried for GET, HEAD and OPTIONS only

  • a 407 Proxy Authentication Required response, or any status you list in retry_statuses: retried for any method

Anything else is returned or raised exactly as httpx would. httpx reports a failed TLS handshake with the target as a connect error, so that also counts against the proxy. Requests with a streamed or multipart body are sent once and not retried. One connection pool is kept per proxy used, so connections are reused when a proxy comes round again.

Parameters:

  • provider – Where proxies come from

  • algorithm – Selection algorithm, as for provider.get_proxy()

  • max_retries – How many more proxies to try after the first one fails

  • retry_statuses – Extra response status codes treated as a failed proxy, e.g. {403, 429}. 407 is always included.

  • transport_options – Passed to each underlying httpx.HTTPTransport, e.g. verify= or http2=True

Example:

import httpx
from proxyproviders import Webshare
from proxyproviders.httpx_transport import RotatingTransport

transport = RotatingTransport(Webshare(api_key="your-api-key"), max_retries=3)

with httpx.Client(transport=transport) as client:
    response = client.get("https://httpbin.org/ip")

The async version of RotatingTransport, for httpx.AsyncClient.

It behaves the same way and takes the same arguments. Asking the provider for a proxy runs in a worker thread, so a provider refreshing its list from the vendor’s API does not block the event loop.

The reverse of to_url(): percent-encoded credentials are decoded. See from_string(), which this is an alias of, for every accepted form.

property scheme: str

The URL scheme used to connect to this proxy.

protocols lists what the proxy supports. A proxy that supports http or https (or does not say) is reached over http. A SOCKS-only proxy, e.g. protocols=["socks5"], is reached over that SOCKS scheme.

to_url(protocol: str | None = None) → str[source]

Convert proxy to URL format for use with HTTP clients.

Parameters:

protocol – The protocol to use in the URL. Defaults to scheme, which is http unless the proxy only supports SOCKS.

Returns:

Proxy URL in format ‘protocol://username:password@host:port’. The username and password are percent-encoded, so characters such as @, :, # or / in them do not change where the URL points. A proxy with no username and no password gives ‘protocol://host:port’.

Format proxy for different HTTP clients and tools.

A SOCKS-only proxy (protocols=["socks5"]) is formatted with its SOCKS scheme. Your HTTP client needs SOCKS support for that: requests[socks] or httpx[socks]. aiohttp and Scrapy have no built-in SOCKS support.

Parameters:

  • format_type – Output format (default: URL string). See ProxyFormat for every format and what it is passed to.

  • kwargs – Format-specific options: protocol for URL and PLAYWRIGHT, protocols for REQUESTS and URLLIB

Returns:

Formatted proxy data

Examples

>>> proxy.format()  # Default URL string
'http://user:pass@192.168.1.1:8080'

>>> proxy.format(ProxyFormat.REQUESTS)  # requests.get(url, proxies=...)
{'http': 'http://user:pass@192.168.1.1:8080', 'https': 'http://user:pass@192.168.1.1:8080'}

>>> proxy.format('curl')  # String also works
['-x', 'http://user:pass@192.168.1.1:8080']

>>> proxy.format(ProxyFormat.HTTPX)  # httpx.Client(proxy=...)
'http://user:pass@192.168.1.1:8080'

>>> proxy.format(ProxyFormat.PLAYWRIGHT)  # browser.new_context(proxy=...)
{'server': 'http://192.168.1.1:8080', 'username': 'user', 'password': 'pass'}

proxyproviders.models.formats.parse_proxy_string(text: str) → Dict[str, Any][source]

Parse one proxy written as text into the fields of a Proxy.

Accepted forms:

  • a URL: http://user:pass@host:port, socks5://host:port

  • host:port:user:pass, the line format many providers export, and host:port

  • user:pass@host:port (treated as http)

Percent-encoded credentials in a URL are decoded. In host:port:user:pass the password is everything after the third colon, so it may itself contain : or @. An IPv6 host is written in square brackets, e.g. [2001:db8::1]:8080.

Raises:

ValueError – if the text is not one of these forms
